# Starlight Recipes

Recipe and drink guide for the Starlight Space Station 14 server.

Live at https://starlight-recipes.pages.dev

Pushes to `main` deploy automatically through Cloudflare Pages. The site is two static files: `index.html` and `sprite.png` (item icons). No build step.

To update: edit the files and push to `main`. Cloudflare redeploys within a minute or two.
